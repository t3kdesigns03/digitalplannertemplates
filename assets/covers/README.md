# Cover Concepts

Reference art for different visual directions. The planner covers themselves are generated in code. These images are the visual targets, not files the build uses.

## Switching styles

Set `"style"` in `planner.config.json`, or override it per build:

```bash
node src/cli.js --style galactic-cute
PLANNER_STYLE=galactic-cute npm run build
```

| Style | Generated by | Reference art |
|---|---|---|
| `soft` (default, alias `pastel`) | `softCover` in `src/pages/cover.js`, the original soft pastel SVG cover | — |
| `galactic-cute` | `galacticCover` in `src/pages/cover.js`, using the sky from `src/art/galactic.js` | `galactic-cute/` |

Styles are registered in `src/styles.js`. To add one, register it there, add a cover function in `src/pages/cover.js`, and put its reference art in a folder here named after the style.

## galactic-cute/
Cute pastel aliens kept, but placed in much more dramatic galactic backgrounds. This is the target for the `galactic-cute` style.
- galactic-cute-1-hill-nebula.jpg
- galactic-cute-2-floating-galaxy.jpg

Do not delete the original soft pastel cover generation. New styles should be additive.
